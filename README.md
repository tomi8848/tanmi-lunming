# 坛醚论命

**六爻起卦 · 紫微斗数 · 子平八字**

一款支持 Windows 和 Android 的中文离线排盘工具。集起卦、命盘查阅、历史命例管理与图片导出于一体，也可自行接入 DeepSeek、OpenAI 或兼容 API，对当前盘面进行 AI 解读和连续追问。

本地排盘不需要账号或 API Key。AI 功能按需启用，需要网络及自行配置的 API 服务。

## 主要功能

### 六爻起卦

- 系统随机铜钱起卦、系统时间种子起卦，以及手动录入六爻。
- 起卦前提供 5 秒静心等待，界面显示时间干支。
- 展示本卦、之卦、互卦，以及纳甲、六亲、六神、世应、伏神、旬空等信息。
- 本卦与之卦逐爻对照，标注动爻，便于比较阴阳变化。
- 查阅六十四卦的卦辞、爻辞、《彖》、大象、小象，以及乾坤用九、用六和《文言》。这里的卦文不包含《系辞》《说卦》等跨卦篇章。

系统时间模式是可复现的时间种子模拟铜钱法，并非梅花易数时间起卦。

### 紫微斗数

- 支持公历、农历、闰月输入和传统十二宫命盘。
- 支持独立天盘、地盘、人盘，以及各盘的本命、大限、流年查看。
- 可直接输入流年年份；本命盘也标注所选年份的流年、小限位置和虚岁。
- 查看星曜、亮度、四化、流曜及各宫年龄信息；三方四正以宫位底色高亮展示。
- 提供地方平太阳时、真太阳时选项，并显示校正前后时刻及偏移。
- 附天地人盘的中州派用法与校时说明，供核对盘式选择。
- 安卓支持竖屏十二宫总览、完整大盘及紧凑／标准／大字三档字号。

### 子平八字

- 展示四柱、十神、藏干、神煞、大运及流年干支。
- 神煞可按四柱或名称查看，提供对应位置与查表依据。
- 五行统计同时展示明干、藏干与表层数量，列明统计来源。
- 支持未知时辰的三柱排盘，不补造时柱。

含藏干的五行份数是统计展示，不直接等同于旺衰、格局或用神判断。

### 历史、保存与导出

- 六爻、紫微、八字分别管理历史记录和手动保存的卦象／命例。
- 每个模块的历史区、保存区各支持 **5000 条**，可将历史手动转为保存。
- 支持命名、笔记、搜索和删除；一键清除历史不会删除手动保存的记录及 AI 存档。
- 支持主要盘面导出为 PNG 图片，安卓可调用系统分享。
- 支持结果文本与 JSON 导出；当前版本没有 JSON 导入功能。

### 可选 AI 解读

在 **AI 设置**中选择服务，填写 API Key、模型名称并测试连接；自定义兼容服务还可填写 HTTPS 地址及接口类型。可选择模型思考强度，实际支持的档位由模型和服务商决定。

六爻、八字、紫微使用各自独立的提示词，明确分析体系、盘面依据和时间口径。紫微提供当前盘式及所选年份的流年、小限、大限背景；八字提供原局、起运与近期年份信息；六爻围绕本次占问、动爻和起卦时刻分析。

支持连续追问、手动保存分析和导出文本。每个模块另有最多 **5000 份 AI 分析存档**。当前回复在生成完成后显示，不逐字流式输出；追问使用同一盘面和有限的近期对话，并非无限记忆。

软件不提供 API Key 或模型额度，服务费用以所选提供商为准。接口兼容性不代表与服务商存在合作或背书。

## 数据与隐私

排盘和记录管理在本机完成，电脑与手机之间**不会自动同步历史、命例或 API 设置**。

主动进行 AI 分析时，当前分析需要的出生资料、盘面、占问及相关对话会发送到所选服务；不会自动上传整个历史库。姓名、出生地和笔记不自动加入提示词，但自行输入的问题可能包含这些信息，请在发送前核对。连接测试也会调用所选 API。

API Key 使用 Windows 系统密钥保护或 Android Keystore 加密保存。普通命例和已保存的 AI 文本没有额外加密。第三方服务如何处理请求数据，以其自身政策为准。

Windows 的个人数据位于 `%APPDATA%\san-shi-paipan`。完整本机备份时，先退出软件，再复制整个目录；仅复制 EXE 不会迁移历史。更换设备后 API Key 需要重新填写。

安卓卸载应用或清除应用数据会删除本机记录。图片、文本或 JSON 导出不等于可一键恢复的完整数据备份。

## 排盘约定

- 输入年份范围为 1901–2099 年，输入时刻采用标准北京时间 UTC+8；海外当地时刻、历史夏令时需先换算。
- 八字、六爻采用 23:00 换日。紫微按软件的晚子时和闰月约定处理。
- 紫微按农历正月初一换流年、按虚岁查看运限；八字以立春作为流年分界，两者不混用。
- 真太阳时使用经度差与近似均时差，城市经度也是近似值；出生时刻接近时辰边界时，应核对地点与时间。
- 神煞、天地人盘等规则存在流派差异，具体采用口径可在软件说明及随附来源文件中查阅。
