# 紫微斗数格局规则与资料来源

本软件的“格局”页只按当前天／地／人本命盘识别已核验、可逐宫核对的组合。规则及简要倾向由开发者依据下列公开资料重新整理，没有直接复制文章正文或将古代断语作为事实结论。

主要资料：[紫微研习社 iztro《紫微斗数格局》](https://docs.iztro.com/learn/pattern)。该文说明格局流派口径不一，许多旧断语不适合直接用于现代生活。原项目参考：[Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu)。

| 本版收录 | 识别口径 |
| --- | --- |
| 紫府同宫 | 紫微、天府同守寅或申命宫 |
| 武贪同行 | 武曲、贪狼同守丑或未命宫 |
| 巨日同宫 | 太阳、巨门同守寅或申命宫 |
| 日月同宫 | 太阳、太阴同守丑或未命宫 |
| 石中隐玉 | 巨门守子或午命宫 |
| 杀破狼 | 七杀、破军、贪狼三曜齐集命宫三方四正，且其中一曜守命 |
| 阳梁昌禄 | 太阳、天梁、文昌、禄存四曜齐集命宫三方四正 |
| 府相朝垣 | 收录天府在官禄、天相在财帛会照命宫这一明确形式 |
| 辅弼拱主 | 紫微守命，左辅右弼均在命宫三方四正，或两曜分夹命宫 |
| 君臣庆会 | 只收录紫微、左辅、右弼同守命宫，且命宫三方四正不见六煞或生年化忌这一严格形式；其他流派变式暂未自动标记 |
| 左右同宫 | 左辅、右弼同守命宫或身宫 |
| 左右夹命 | 左辅、右弼分居命宫两侧相邻宫 |
| 魁钺夹命 | 天魁、天钺分居命宫两侧相邻宫 |

“需合看条件”会列出所涉宫位中的六煞或生年化忌，以提醒综合判断，不统一判作破格。程序不会因为流年／大限信息而改变本命格局。页面上的倾向说明是传统象义的简短转述，不是科学预测，也不作为职业、财富、健康或人生结果的判断依据。
